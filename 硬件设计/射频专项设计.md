# 射频专项设计

> 本文档聚焦本遥控板 2.4GHz 无线链路的板级射频（RF）设计要点。
> **边界声明**：本板 NRF24L01 采用**成品模块插接**方案（NRF1 为 2×4 排针插座），射频前端性能（发射功率、接收灵敏度、天线匹配）主要由模块本身决定。板级设计能做且必须做好的是：**供电质量、净空区保护、布线规避干扰**。本文档不讨论模块内部射频电路。

## 1. NRF24L01 射频基础

| 项目 | 说明 |
|---|---|
| 频段 | 2.4GHz ISM（2400~2525MHz） |
| 信道 | 126 个（信道 0~125，间隔 1MHz） |
| 调制 | GFSK |
| 数据率 | 250kbps / 1Mbps / 2Mbps（距离与速率权衡） |
| 发射电流 | 峰值约十几 mA（0dBm 时），突发式 |
| 供电 | 3.3V（本板由 U1 LDO 输出，NRF1 的 Pin1） |

遥控器应用建议：**250kbps 或 1Mbps**（低速率换更远距离与抗干扰裕量），帧率 50Hz 下带宽完全够用。

## 2. 布局净空区要求（板级射频第一要务）

模块天线通常位于模块边缘（PCB 板载天线或陶瓷天线），其周围电磁环境直接影响发射效率：

1. **天线端净空**：模块天线一侧（伸出板外的方向）在顶层、底层均**不铺铜、不走线、不放元件**，净空区建议 ≥5mm
2. **模块朝向**：天线端尽量朝向板外/空旷侧，避免被电池、金属外壳贴近遮挡（装配时注意）
3. **安装位置**：NRF1 插座布置在板边（见[PCB布局设计](PCB布局设计.md)），天线远离大电流回路与开关节点（VBAT_SW 主供电回路及 U2 SW 节点 $1N192 噪声较强，走线要短且远离模块）
4. **外壳影响**：若使用金属外壳，天线位置必须开窗或使用外置天线；塑料外壳影响较小

## 3. 供电与去耦（射频稳定的根基）

NRF 发射瞬间电流阶跃变化，供电阻抗过高会造成电压跌落→发射功率不稳→丢包：

- NRF 所在 3V3 网络已有就近去耦电容（C8/C11/C12，100nF），装配时确认无虚焊
- 3V3 主干储能依赖 U1 LDO 输出端电容，纹波建议控制在 **50mV 以内**（示波器在模块电源引脚处实测）
- 调试时若出现"近距离正常、距离一远就丢包"，优先测发射瞬间的 3V3 跌落，详见[电源完整性设计](电源完整性设计.md)与[调试指南](../调试指南.md)

## 4. 干扰与共存规避

### 4.1 与 WiFi 的信道重叠

2.4GHz 频段与 WiFi（信道 1~13）重叠。NRF 信道选择建议：

- 避开 WiFi 常用信道 1/6/11 对应的频率（2401~2423 / 2426~2448 / 2451~2473MHz 附近）
- 常用经验值：选择 **信道 100 以上的高频段**（如 2500MHz 附近），日常环境干扰相对少
- 固件侧如实现跳频，优先在 3~5 个预选干净信道间跳，详见[固件设计规范](../软件固件/固件设计规范.md)

### 4.2 板内干扰源

| 干扰源 | 机理 | 规避 |
|---|---|---|
| U2 升压 SW 节点（$1N192） | 开关边沿快、辐射强，噪声经电源线进模块 | 走线短小，靠近 U2，远离模块与天线净空区，3V3 就近去耦 |
| SPI 时钟（NRF_SCK） | 谐波可能落入 2.4GHz | 走线短，必要时降低 SPI 速率 |
| 数字地回流 | 地弹噪声经电源线进模块 | 模块供电就近去耦，GND 铺铜完整 |

## 5. 无线距离测试方法

1. **场地**：开阔无遮挡环境（操场/空地），天线方向一致
2. **方法**：固件以固定帧率持续发送，接收端统计 10 秒内的**丢包率**与**RSSI**
3. **判据建议**：
   - 目标距离内丢包率 <1%（遥控应用）
   - 记录最远可靠通信距离作为基线，后续改版对比
4. **异常排查顺序**：供电纹波 → 天线遮挡 → 信道干扰 → SPI 通信稳定性，对应步骤见[调试指南](../调试指南.md)

## 6. 下版改进方向

- 如需更远控制距离：外置 SMA 天线座 + 鞭状天线
- 如需更强抗干扰：预留 PA/LNA 放大模块接口
- 丝印标注天线净空区（"Keep Out"），防止改版时误铺铜
